# CelestJux Front Shop

Nine coding agents in a 16-bit office. Every desk lights up off a real tool call;
the couch fills when the house goes quiet. Walk in, press Enter next to someone —
and if anyone else has the page open, you will see them walking around too.

The desks are a snapshot, refreshed by `publish_arena.py`; the visitors are live.
The page says which is which. Art: LimeZu "Modern Interiors" — see
`sprites/CREDITS.md`.
