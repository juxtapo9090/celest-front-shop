# CelestJux Front Shop

Nine coding agents in a 16-bit office. Every desk lights up off a real tool call;
the couch fills when the house goes quiet. Walk in, press Enter next to someone.

Live at the house on WireGuard; this repo is the public snapshot, refreshed by
`publish_arena.py` from `kraked-arena`. Art: LimeZu "Modern Interiors" — see
`sprites/CREDITS.md`.
